## 구현 결정

기존 파일에 병행 변경이 있어 `prototype/mobile/`에 별도 모바일 버전을 작성했다. `routes.mjs`의 정상·지연 시각과 기차 SVG를 재사용했다. 기존 시설 계산은 개략도 좌표에 고정 배율을 적용하고 있어, 신규 시안에서는 가정한 구간 길이를 별도 명시하여 경로별 합산으로 계산했다. 거리·시간을 가상 설정으로 표시하고 성공·안전 여부를 단정하는 문구는 사용하지 않았다. 공개 배포본과 제출 ZIP은 수정하지 않았다.

승차권과 환승 카드, 두 열차 진행, 시설 경유·현재 위치 선택, 속도·이용·대기시간 변경, 정상·지연 전환, 키보드 포커스와 상태 안내를 구현했다. 실제 발권과 코레일 계정·GPS 연결은 제외했다.

## 검증과 수정

신규 계산 검사 4개와 기존 앱 검사 29개가 통과했다. CUA 도구의 커널 초기화 오류로 임시 headless Chrome을 이용하여 티켓 탭·안내창과 Escape·화면 전환 후 포커스·시설 선택·현재 위치 변경·정상/지연·뒤로 가기·키보드 이동을 확인했다. 320·390·1280px에서 세 화면의 가로 넘침이 없고 브라우저 및 정적 자산 오류가 없었다. 화면 검토 후 환승 상세의 자기 자신으로 연결되는 중복 버튼을 제거하고 동작 검사를 다시 통과했다. 실제 휴대폰 및 현장 보행 검증은 수행하지 않았다.

## 오송역 시설 안내 재구성 요청과 수정

> 오송역 장애인 분들을 위한 점자 안내판 있잖아 그거 이용해서 시설공유 안내 새로 구성해줄래 이건 없는거만도 못함

> 제미나이는 이거 가져오던데 한번 다시 찾아봐

> http://localhost:8088/#demo 여기 들어가면 제미나이가 만든거 이거 참고 하면 되는거 아니야 아니면 더 찾아보고

> 수정해보자

기존 보관 사진의 제목을 판독하여 제천역 3층 안내판임을 확인했다. 재검색으로 아카이브오송의 오송역사 점자안내도 사진을 찾고, 사진 안의 1·2·3층 표기와 공간 연결을 확인했다. 사용자 지정 localhost:8088 시안의 시설 선택·층 전환·경로 재생 흐름을 참고했다. 해당 시안의 거리 계산은 두 점 사이 직선거리에 고정 배율을 적용하고 있어 실제 거리 근거로 사용하지 않았다.

기존 T자 지도 대신 층별 재구성 안내도, 시설 핀, 확대·축소, 경로 단계 선택·재생·정지를 모바일 버전에 연결했다. 거리는 기존 예시 구간 합산을 유지하고 실제 보행 거리·무장애 경로로 확정하지 않았다. 도면 설명에 출처 링크와 추정 범위를 표시했다. 새 의존성·배포·기존 데스크톱 버전 변경은 추가하지 않았다.

검증: 모바일 자동 검사 5개 통과. 임시 Chrome에서 시설 선택 후 층 전환, SVG 핀의 Enter 선택, 확대·초기화, 경로 자동 재생·정지·다음 단계, 지연과 정보 누락 계산, 뒤로 가기·포커스를 확인했다. 320·390·1280px에서 페이지 가로 넘침 및 자산·JavaScript 오류가 없었다. 실물 기기와 현장 동선은 검증하지 않았다.

> 음 왜 아직도 이거야?

사용자 화면에 이전 T자 지도가 남아 있어 HTML의 CSS·앱 모듈과 안내도 모듈 import에 버전 쿼리를 추가했다. 8080 서버 응답에서 새 버전 경로를 확인하고, 버전이 붙은 페이지를 임시 Chrome에서 열어 새 SVG 지도 1개·층 선택 3개·이전 T자 지도 0개를 확인했다. 열린 사용자 브라우저는 CUA 커널 오류로 직접 새로고침하지 못했다.

> 수업용 프로토타입 · 실제 승차권으로 사용할 수 없어요 이런 문구는 빼자 이거는 저렇게 할게 아니라 위에 똑같이 넓게 표시되야 하는거 아니야

하단 수업용 문구를 제거했다. 다음 열차 승차권을 접힌 details에서 상시 표시 section으로 바꾸고, 현재 열차와 동일한 ticket 컴포넌트를 유지했다. 상단 비공식 표시와 티켓의 SAMPLE·가상 예시는 유지했다. 320·390·1280px에서 다음 승차권의 표시 여부·두 승차권의 동일 폭·페이지 가로 넘침 없음을 확인했다.

> 문구 내용이 들어가야 할거 같은데 지연으로 시간 단축이런 느낌

시설 경유 화면의 남은 시간 아래에 지연 시에만 원인을 설명하는 안내를 추가했다. 첫 열차 도착이 14:10→14:20으로 늦어져 환승 간격이 15분→5분으로 줄고, 다음 열차 출발은 14:25로 동일함을 표시한다. 정상 운행으로 돌아가면 안내를 숨긴다. Chrome 320px에서 지연·정상 전환과 안내 표시·해제, 가로 넘침 없음을 확인했다.

> 이거 지워 필요 없는것들이 왜 있는거야 이건 프로토 타입인데

시설 안내 화면의 ‘오송역 원본 안내도와 출처’ 펼침 영역과 링크를 제거하고 참고 자료는 README에만 남겼다. Chrome에서 출처 영역 제거와 지도·재생 버튼 유지 여부를 확인했다.

> 이것도 그래보통 사람들이 걸어가지 누가 걷는 속도 까지 생각하냐고

걷는 속도 선택을 제거하고 보통 걸음 1.2m/s 기준으로 자동 계산하도록 유지했다. ‘예상시간을 비교해보세요’를 ‘예상 소요시간’으로 바꾸고 수식 설명을 간단한 문장으로 정리했다. Chrome에서 속도 선택 제거와 시설·대기시간 변경에 따른 계산 유지를 확인했다.

> 시설 이용시간은 제외 해야하는거 아니야 단순하게 이동시간만 제공하는게 좋지 않아 너무 난잡한거 같은데 너는 어떠데

> 예상 소요시간이 아니라 도보이동 예상 소요시간이런식 아니야 문구 이런거 안고칠래

제목을 ‘도보 이동 예상시간’으로 바꾸고 이동·층간 이동만 표시했다. 이용·대기 입력, 탑승 준비, 합계와 남는 시간 결과를 화면에서 제거했다. 선택 시설을 거쳐 다음 승차홈까지의 경로와 이용·대기 제외 문장을 표시했다. 모바일 검사 5개 통과. Chrome에서 바로 환승·화장실·편의점의 도보 시간, 시설 앞 현재 위치, 지연과 이동시간의 분리, 입력·합계 제거와 320px 가로 넘침 없음을 확인했다.

> 오송역에 있는 편의 시설 포함시키고 너무 적음 그리고 위치가

> 너무 아래야 올려야함

도보 이동 예상시간을 시설 선택 바로 아래, 지도 위로 이동했다. 기존 오송역 시설 자료를 재사용해 약국·수유방·물품보관함·던킨도넛·충북대학교 열린쉼터를 추가했다. 시설 선택에 층을 표시하고 각 시설의 지도 핀·층 전환·경로 단계·도보 시간과 연결했다. 시설명·층과 달리 핀 좌표와 거리는 예시다. 최신 코레일 페이지는 웹 도구에서 접근 제한 안내가 나와 현재 영업 여부까지 재검증하지 못했다. 모바일 자동 검사 6개와 Chrome의 8개 선택지·카드 순서·추가 시설 층/핀/경로·320/390/1280px 가로 넘침·JavaScript 오류 검사를 통과했다.

> 이거 더 개선해봐 글자랑 도형이랑 겹치느 분 있어

승강장마다 이름은 상단·경로는 하단으로 분리하고 계단 연결 표시를 오른쪽에 정렬했다. 하차/다음 열차 표시는 경로 아래 별도 줄로 옮겼으며 마지막 승강장과 하단 설명 사이 여백을 확보했다. 2·3층의 중복 시설 글자와 경로를 가로지르는 중앙 문구를 정리하고, 경로를 시설 핀·글자 뒤에 그리도록 순서를 바꿨다. 위치 점도 핀 옆에 배치했다. 모바일 검사 6개와 Chrome 320/390/1280px 세 층 화면 검사·승강장 이름과 경로선의 기하학적 겹침 검사·시설 선택을 통과했다. 세 층 SVG 캡처를 직접 확인했다.

> 2층 3층 안내도가 저렇게 생김?

> 너무 단순함

기존 직사각형 도식이 실제 형태를 충분히 반영하지 못했음을 인정하고, 확보한 오송역사 점자안내도 및 보관된 입체 안내도·관광안내소 약도를 다시 대조했다. 2층은 양 끝 이동 설비·왼쪽 역무실·오른쪽 긴 대합실의 연결, 3층은 서편의 긴 대기 구역과 계단·승강기가 반복되는 꺾인 연결로를 기준으로 외곽과 벽체를 수동 재구성했다. 출입 틈·승강기·계단·대기 좌석과 시설 구역을 분리하고 SVG 높이를 늘려 세부 구조를 읽을 수 있게 했다. 시설 핀과 승차홈별 연결·거리의 실측은 하지 않았으며 예시 범위는 유지했다.

검증: 모바일 검사 6개 통과. Chrome 320/390/1280px에서 세 층 가로 넘침, 승강기·대기 구역, 전체 시설 선택·경로 단계와 JavaScript 오류를 검사하고 2·3층 캡처를 직접 확인했다. 화면 검토 후 WC 구획과 수유실 핀 사이 간격, 승강기 글자·외곽선 간격을 보완했다.

> 이동 경로 화살표로 해볼까

점선 경로를 실선과 방향 화살표로 변경했다. 시설까지 가는 방향은 노란색, 다음 승차홈으로 돌아가는 방향은 하늘색으로 구분하고 겹치던 왕복 구간을 나눴다. 승강장에서도 하차 후 연결로로 나가는 방향과 연결로에서 다음 열차로 향하는 방향을 반대로 표시한다. 현재 위치가 시설 앞이면 복귀 경로만 표시한다. 화살표는 움직이지 않아도 읽을 수 있게 각 구간 중앙에 배치했다. 자동 검사 7개와 Chrome 세 층/전체 시설/현재 위치 전환/320·390·1280px 화면 검사를 통과하고 3층 및 승강장 캡처를 확인했다. 실제 보행 경로 검증은 수행하지 않았다.

> 그리고 편이 시설 이미지도 첨부하는게 좋을거 같은데

시설을 선택하면 도보 이동 예상시간 아래·지도 위에 해당 시설의 사진과 층을 표시했다. 코레일 시설 자료의 편의점·던킨·열린쉼터·보관함 사진을 확보하고 실제 간판·시설을 확인했다. 수유실은 코레일 원본이 작은 썸네일이어서 보관된 큰 사진을 사용했다. 약국 원격 사진은 JPEG가 아니어서 사용하지 않고 약국·편의점 간판이 함께 보이는 보관 사진을 사용했다. 냉난방 맞이방 사진은 열린쉼터 사진으로 대신 사용하지 않았다. 물품보관함 원본은 작게 표시했다. 사진 확대·닫기·Escape·로딩 실패 문구를 구현했다. Chrome에서 7개 시설 사진, 위치, 확대 및 Escape, 320/390/1280px 가로 넘침과 이미지 요청 실패 시 대체 문구를 확인했다.

> 사진 보여주는거 좀 바꾸고 싶은데 내가 선택해야 나오니까 좀 그런데 더 좋은 방법 없나

> 그렇게 해볼래

시설 선택을 2열 사진 카드로 변경했다. 선택 전에도 사진·시설명·층이 보이며 선택 카드에는 테두리와 체크를 표시한다. 별도의 큰 사진 영역은 제거했다. 카드 선택 버튼과 사진 확대 버튼은 중첩하지 않고 별도로 두었으며 확대는 시설 선택을 바꾸지 않는다. 바로 환승은 사진 없는 가로 카드로 유지했다. 이미지 로딩 오류 시 해당 썸네일만 ‘사진 준비 중’으로 대체하고 선택은 유지한다. Chrome에서 사진 7개·2열·전체 시설 선택/지도 핀·독립 확대/Escape·키보드 Enter·오류 처리·320/390/1280px 넘침 없음을 확인하고 카드 캡처를 확인했다.

- “추천방향으로 가자” — 시설 선택 전에 바로 환승 대비 추가 도보 시간을 표시했다. 지연 시 선택 경로의 도보 시간이 남은 시간 이상이면 바로 환승으로 바꾸는 버튼을 제공하고 층별 안내도에 연결 층 버튼을 추가했다.
