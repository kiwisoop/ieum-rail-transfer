# 코레일톡 승차권 환승 UX 개선안

기존 프로토타입과 별도로 작성한 모바일 시안이다. 사용자가 제공한 코레일톡 ‘나의 티켓’ 화면을 참고하여 남색 헤더·티켓 탭·승차권 표를 구성하고 환승 안내 카드를 추가했다. [GitHub Pages에서 체험할 수 있다](https://kiwisoop.github.io/ieum-rail-transfer/mobile/).

## 실행

저장소 최상위 폴더에서 `python3 -m http.server 8080 --bind 127.0.0.1`을 실행한 뒤 <http://127.0.0.1:8080/mobile/>에 접속한다. 모바일을 기본으로 만들었으며 PC에서는 폭 440px의 화면으로 확인할 수 있다. 휴대폰에서 로컬 서버에 접속하려면 별도 네트워크 설정이 필요하다.

승차권 → 환승 안내 → 하차 후 시설 경유 순으로 체험한다. 브라우저 뒤로 가기와 화면 상단 뒤로 가기로 이동할 수 있다. 체험 설정에서 정상·10분 지연, 여정 시각을 변경한다. 시설 경유에서는 현재 위치와 시설에 따라 도보 이동 예상시간이 달라진다. 보행속도는 보통 걸음 기준으로 자동 적용하며 화면에서 입력받지 않는다.

## 계산과 한계

- 목포 → 오송 → 부산 승차권·열차번호·좌석·시각·승차홈은 모두 가상 예시다. 실제 예약·발권·결제나 코레일 계정 연결은 없다. QR 대신 SAMPLE 표시를 사용한다.
- 기존 `routes.mjs`의 정상 14:10·지연 14:20 도착, 14:25 출발 계산과 `assets/train.svg`를 재사용한다.
- 신규 지도는 경로 설명을 위한 개략도다. 승차홈→대합실 60m, 대합실→7번 홈 90m, 대합실→화장실 40m, 대합실→편의점 70m는 전부 가정한 거리다. 화면 픽셀로 실거리를 측정하지 않았다. 실제 평면도·거리·통행 가능 여부는 미검증이다.
- 평지 이동은 거리÷속도로 산정한다. 1.2m/s는 [서울교통공사 공개 산정 방식](https://data.seoul.go.kr/dataList/OA-13290/F/1/datasetView.do)을 참고한 기준이며 오송역 실측 평균이 아니다. 0.9m/s, 층간 이동 45초, 탑승 준비 2분도 체험용 가정이다. 엘리베이터 경로 및 혼잡도 예측은 제공하지 않는다.
- 사용자 화면에는 평지 이동과 층간 이동을 합친 도보 이동 예상시간만 표시한다. 시설 이용·대기·탑승 준비는 합산하지 않으며 방문 가능 여부나 남는 시간을 계산하지 않는다. 기존 routePlan의 합계 계산은 호환성을 위해 남아 있지만 모바일 화면에서는 walking 값만 사용한다.
- 하차 버튼은 체험 시각을 도착 예정시각으로 옮긴다. 현재 위치는 수동 선택이며 GPS 추적이 아니다. 진행바는 시각 비율이며 실제 탑승 확인이 아니다.

## 확인

`node --test mobile/tests.mjs` (저장소 최상위 폴더 기준). 기존 앱 검사는 `node --test tests.mjs`로 별도 실행한다.

참고 화면: 사용자가 제공한 [위키트리 기사](https://www.wikitree.co.kr/articles/1106155)의 ‘좌석변경 승차권 확인’ 캡처. 좌석변경 기록을 환승 승차권으로 해석하지 않았으며, 별도 연결 승차권을 구성했다. 비공식 수업용 개선 시안이고 실제 코레일 앱을 수정한 결과물이 아니다. 구현 도구는 OpenAI Codex다.

## 오송역 층별 안내 (2026-11-11 수정)

[아카이브오송](https://hiosong.kr/cheongju/place/?id=a3a72a21-c7ff-4a38-bfb8-7f477021faca)에 게시된 ‘오송역사 점자안내도’ 사진을 직접 확인했다. 사이트는 2026-09-23 촬영이라고 밝히며 원본은 1층 출입구·2층 대합실·3층 승강장 연결로를 보여 준다. 원본 자료 출처는 이 README에 기록하며 사용자 화면에는 표시하지 않는다. 제천역 점자 안내판 사진은 오송역의 배치 근거로 사용하지 않았다.

지도는 공간 연결을 단순화한 SVG이며 정확한 벽체·방위·시설 입구를 복제한 도면은 아니다. KTX 승강장 도식, 3·7번 홈 연결 위치, 편의점 핀은 예시로 보완했다. 지도상의 노란 선은 실제 점자블록이 아니다. 원본 사진만으로 길이·현재 매장·층간 통행 조건을 확인할 수 없어 실제 경로 및 무장애 안내로 제공하지 않는다.

시설 선택 시 해당 층으로 전환된다. 핀은 클릭·Enter·Space로 선택할 수 있으며 확대·축소·층 전환과 단계별 선택을 지원한다. 경로 재생은 2.2초마다 다음 이동 구간의 층을 보여 주는 압축 미리보기다. 시설 이용·대기 시간은 도보 이동 예상시간에 포함하지 않는다. 재생은 체험 시각이나 현재 위치를 변경하지 않는다. 다른 시설·현재 위치·운행 상황 선택이나 화면 이동 시 재생을 멈춘다. 애니메이션 감소 설정에서는 흐르는 선 효과를 끈다.

### 시설 목록 확장

2026-11-11: 도보 이동 예상시간 카드를 시설 선택 아래·지도 위로 이동했다. 기존 `facilities.mjs`의 오송역 자료에서 약국·수유방·물품보관함·던킨도넛·충북대학교 열린쉼터의 이름과 층을 재사용했다. 신규 시설의 지도 좌표와 도보 구간 길이는 가정이며 현재 영업·출입 가능 여부는 미검증이다. 참고: [코레일 오송역 안내](https://www.korail.com/ticket/train/stationGuide/station/view?stationSeq=10280979), [열린쉼터 안내](https://fund.chungbuk.ac.kr/www/contents.do?key=1176). 코레일 페이지 최신 조회 시 접근 제한 안내가 반환되어 기존 자료를 사용했다.

### 안내도 외곽 재구성

2층의 왼쪽 역무실과 오른쪽 긴 대합실, 양 끝의 층간 설비 및 3층의 서편 대기 구역·꺾인 연결로·계단·승강기 묶음을 오송역 점자 안내도 사진과 대조하여 수동으로 다시 그렸다. 출입 틈과 대기 좌석을 보완했다. 이는 사진을 참고한 비축척 도식이며 실측 벽체·입구·현재 시설 위치를 검증한 실내 내비게이션 지도가 아니다. 각 시설 핀과 열차별 승차홈 연결은 여전히 예시다.

### 시설 사진

시설 선택은 2열 사진 카드이며 선택 전부터 사진·시설명·층을 표시한다. 카드 선택은 경로·시간을 갱신하고 별도 확대 버튼은 선택을 바꾸지 않고 사진을 확대한다. 별도의 큰 사진 영역은 제거했다. 사진 로딩 실패 시 문구로 대체한다. 보관함 사진은 작은 원본을 늘리지 않는다. 화장실 사진은 특정 핀의 입구를 확정한 사진이 아니라 화장실 주변 참고 사진이다. 사진만으로 현재 영업 여부를 판단하지 않는다.
